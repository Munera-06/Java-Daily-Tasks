# Day 10 – Task 3: Prime Number Checker

## Project Overview

The Prime Number Checker is a simple Java program that checks whether a given number is a prime number or not.

A prime number is a natural number greater than 1 that has exactly two factors: 1 and itself.

**Examples:**
- 2 – Prime Number
- 5 – Prime Number
- 7 – Prime Number
- 9 – Not a Prime Number
- 15 – Not a Prime Number

## Technology Used

- **Programming Language:** Java
- **IDE:** Eclipse

## Program Description

This program accepts a number from the user and checks whether it is divisible by any number other than 1 and itself.

### How the Program Works

1. Get a number from the user using the Scanner class.
2. Check whether the number is less than or equal to 1.
3. If the number is greater than 1, use a loop to check its divisibility.
4. Check whether the number is divisible by any value from 2 up to the number before it.
5. If it is divisible, mark it as a non-prime number.
6. If no divisor is found, display that it is a prime number.
