# Day 10 – Task 4: Sum of Digits

## Project Overview

The Sum of Digits program is a simple Java application that calculates the sum of all digits in a given number.

For example:

- Input: 1234
- Calculation: 1 + 2 + 3 + 4
- Output: 10

## Technology Used

- **Programming Language:** Java
- **IDE:** Eclipse


## Program Description

This program accepts a number from the user and calculates the sum of its individual digits using a loop and arithmetic operators.

### How the Program Works

1. Get a number from the user using the Scanner class.
2. Initialize a variable to store the sum as zero.
3. Extract the last digit using the modulus (%) operator.
4. Add the extracted digit to the sum.
5. Remove the last digit using the division (/) operator.
6. Repeat the process until the number becomes zero.
7. Display the final sum of the digits.

## Example Output

**Example 1:**

```text

Sum of digits: 10
```

**Example 2:**

```text

```
