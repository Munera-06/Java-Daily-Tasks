# Day 6 – Java Daily Tasks

## 📌 Project Overview

Day 6 contains four Java programming practice tasks developed to improve fundamental programming knowledge, logical thinking, and problem-solving abilities.

These exercises provide hands-on practice with Java concepts and help build confidence in writing, executing, and understanding Java programs.

## 📂 Tasks Included

### 1. Task 1 – Java Programming Practice

This task focuses on practicing Java fundamentals and understanding the basic structure of a Java program. It helps improve familiarity with writing and executing Java code.

**Concepts Practiced:**
- Java class structure
- Main method
- Variables and data types
- Basic Java syntax
- Output statements

### 2. Task 2 – Java Logic Building

This task focuses on developing programming logic by using Java statements and operations to solve a given problem.

**Concepts Practiced:**
- Variables and operators
- Arithmetic operations
- Conditional statements (if required)
- Logical expressions
- Program execution flow

### 3. Task 3 – Java Problem Solving

This task provides practice in understanding a programming requirement and implementing a solution using Java. It helps develop the ability to convert a problem into simple program logic.

**Concepts Practiced:**
- Java syntax
- Variables and data types
- Operators
- Basic problem-solving logic
- Displaying program output

### 4. Task 4 – Java Programming Exercise

This task provides additional practice in applying Java fundamentals to a programming problem. It helps improve coding accuracy and understanding of how different statements work together.

**Concepts Practiced:**
- Java programming fundamentals
- Operators and expressions
- Conditional statements (if required)
- Basic logic implementation
- Debugging and testing

## 🛠️ Technologies Used

- **Java** – Used to write and execute the programming tasks.
- **Eclipse IDE** – Used for coding, compiling, and running Java programs.
- **Git & GitHub** – Used to maintain and manage daily programming exercises.

## 🎯 Learning Outcomes

By completing these tasks, the following skills can be improved:
