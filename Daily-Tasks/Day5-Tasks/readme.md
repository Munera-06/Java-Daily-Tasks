# Day 5 – Java Daily Tasks

## 📌 Project Overview

Day 5 contains four Java programming tasks developed as part of daily coding practice. These tasks are designed to improve basic Java programming knowledge, logical thinking, and problem-solving skills through practical coding exercises.

Each task provides an opportunity to practice Java syntax, write programs, understand program execution, and improve coding confidence.

## 📂 Tasks Included

### 1. Task 1 – Java Programming Practice

This task focuses on practicing the fundamentals of Java programming. It helps understand how to create a Java class, write the main method, and execute a program.

**Concepts Practiced:**
- Java class structure
- Main method
- Variables and data types
- Basic Java syntax
- Output using `System.out.println()`

### 2. Task 2 – Java Logic Building

This task focuses on developing basic programming logic using Java. It provides practice in writing statements and understanding how different operations work.

**Concepts Practiced:**
- Variables and data types
- Operators
- Basic calculations
- Program execution
- Logical thinking

### 3. Task 3 – Java Problem Solving

This task helps improve problem-solving skills by implementing a Java program based on a given requirement. It provides practice in understanding the problem and converting the solution into code.

**Concepts Practiced:**
- Java syntax
- Variables and operators
- Conditional statements (where required)
- Basic programming logic
- Output statements

### 4. Task 4 – Java Loop Practice

This task focuses on practicing repetitive operations using Java loops. It helps understand how loops work and how to control the execution of statements.

**Concepts Practiced:**
- `for` loop
- Loop initialization
- Loop condition
- Increment and decrement
- Repeated execution of statements

## 🛠️ Technologies Used

- **Java** – Used to develop and execute the programming tasks.
- **Eclipse IDE** – Used for writing, compiling, and running Java programs.
- **Git & GitHub** – Used to maintain and manage the daily task files.

## 🎯 Learning Outcomes

By completing these tasks, the following skills can be improved:

- Understanding the fundamentals of Java programming.
- Writing and executing Java programs independently.
- Understanding variables, data types, and operators.
- Developing basic programming logic.
- Practicing loops and repeated execution.
- Improving problem-solving and debugging skills.
- Building a strong foundation for advanced Java concepts.

## ▶️ How to Run the Tasks

1. Open Eclipse IDE.
2. Import or open the Java project.
3. Navigate to the required task folder.
4. Open the Java source file.
5. Run the program using the **Run** option.
6. Check the output in the Eclipse console.

## 📝 Conclusion

Day 5 helps strengthen Java programming fundamentals through four individual coding tasks. By practicing Java syntax, operators, logical statements, and loops, these exercises improve coding knowledge and build a foundation for learning advanced Java concepts.
