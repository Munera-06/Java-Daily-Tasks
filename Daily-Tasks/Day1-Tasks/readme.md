# Day 1 – Java Daily Tasks

## Project Overview

This repository contains Java programming tasks completed as part of my daily coding practice. The main objective is to understand the fundamentals of Java, practise writing programs, and improve logical thinking through hands-on coding exercises.

All programs are developed using Java in Eclipse IDE. These tasks provide a foundation for learning object-oriented programming and solving programming problems efficiently.

## Technologies Used

- **Programming Language:** Java
- **IDE:** Eclipse IDE
- **Platform:** GitHub for version control and project storage

## Tasks Included

### Task 1: Basic Java Programming

**Folder:** `Task1`

This task focuses on understanding the basic structure of a Java program and learning how to write and execute Java code.

**Concepts Covered:**
- Java class structure
- The `main()` method
- Basic Java syntax
- Displaying output using `System.out.println()`

### Task 2: Variables and Data Types

**Folder:** `Task2`

This task focuses on working with variables and understanding how data is stored and used in a Java program.

**Concepts Covered:**
- Variable declaration and initialization
- Data types such as `int`, `double`, `char`, and `String`
- Assigning values to variables
- Displaying variable values

### Task 3: Operators and Calculations

**Folder:** `Task3`

This task focuses on using Java operators to perform calculations and manipulate variable values.

**Concepts Covered:**
- Arithmetic operators
- Assignment operators
- Working with multiple variables
- Performing calculations
- Displaying results

### Task 4: Basic Logic Building

**Folder:** `Task4`

This task focuses on applying basic Java programming concepts to solve simple problems and improve logical thinking.

**Concepts Covered:**
- Writing program logic
- Working with variables
- Understanding the flow of program execution
- Testing program output
- Improving problem-solving skills

## Key Learning Outcomes

By completing these daily tasks, I practised:

- Writing and executing Java programs using Eclipse IDE.
- Understanding Java classes and the `main()` method.
- Declaring variables and working with different data types.
- Using operators to perform calculations and update values.
- Understanding how Java statements execute.
- Identifying errors and correcting mistakes in code.
- Developing logical thinking and programming confidence.

## How to Run the Programs

1. Open Eclipse IDE.
2. Create or open a Java project.
3. Open the required task folder and locate the Java source file.
4. Run the program using **Run As → Java Application**.
5. Check the output in the Eclipse Console.
