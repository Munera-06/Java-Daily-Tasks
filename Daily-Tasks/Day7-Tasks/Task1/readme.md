# Day 7 – Java Daily Tasks

## 📌 Project Overview

Day 7 focuses on practicing Java loop concepts through a number-reversal program. This task demonstrates how a `while` loop can be used to process individual digits of a number and reverse their order.

The program helps improve logical thinking and understanding of loops, arithmetic operators, and number manipulation in Java.

## 📂 Task Included

### 1. Reverse a Number Using a While Loop

**File:** `Reverse-a-Number-Using-a-While-Loop.java`

This program reverses a given integer using a Java `while` loop. It extracts each digit from the original number and builds a new number by placing the extracted digits in reverse order.

**Key Features:**
- Accepts a number from the user.
- Extracts individual digits using the modulus operator.
- Uses integer division to remove the last digit.
- Builds the reversed number step by step.
- Displays the reversed number as output.

**Concepts Practiced:**
- Java `while` loop
- `Scanner` class for user input
- Variables and data types
- Modulus operator (`%`)
- Division operator (`/`)
- Number manipulation
- Loop conditions
