# Day 7 – Java Daily Tasks

## 📌 Task 3 – Print a Right-Angled Star Triangle Pattern Using Nested For Loops

### Project Overview

This task focuses on printing a right-angled star triangle pattern using nested `for` loops in Java. The program uses an outer loop to control the number of rows and an inner loop to print stars (`*`) in each row.

It helps develop a clear understanding of nested loops and pattern-based programming.

### Key Features

- Accepts the required number of rows from the user.
- Uses nested `for` loops to generate the star pattern.
- Prints stars in a right-angled triangle format.
- Increases the number of stars in each row.
- Displays the generated pattern in the console.

### Concepts Practiced

- Java `for` loop
- Nested `for` loops
- Scanner class for user input
- Variables and data types
- Loop conditions and increment operations
- Pattern programming
- Logical thinking

## 🛠️ Technologies Used

- **Java** – Used to implement the star triangle pattern.
- **Eclipse IDE** – Used to write, compile, and execute the program.
- **Git & GitHub** – Used to maintain and manage the source code.

## 🎯 Learning Outcomes

By completing this task, the following skills can be improved:

- Learning how to print patterns using loops.
- Controlling rows and columns through iterations.
- Practicing user input using the Scanner class.
- Improving logical thinking and problem-solving skills.
- Building confidence in Java programming.
