# Day 7 – Java Daily Tasks

## 📌 Task 4 – Print an Inverted Right-Aligned Star Triangle Using Nested For Loops

### Project Overview

This task focuses on printing an inverted right-aligned star triangle pattern using nested `for` loops in Java. The program uses an outer loop to control the rows and an inner loop to print spaces and stars in the required order.

It helps improve the understanding of nested loops, pattern formation, and controlling the number of iterations.

### Key Features

- Accepts the required number of rows from the user.
- Uses nested `for` loops to generate the inverted star pattern.
- Prints spaces to align the triangle towards the right.
- Decreases the number of stars in each row.
- Displays the final pattern in the console.

### Concepts Practiced

- Java `for` loop
- Nested `for` loops
- Scanner class for user input
- Variables and data types
- Loop conditions and decrement operations
- Space and star pattern formation
- Logical thinking

## 🛠️ Technologies Used

- **Java** – Used to implement the inverted star triangle pattern.
- **Eclipse IDE** – Used to write, compile, and execute the program.
- **Git & GitHub** – Used to manage and maintain the source code.

By completing this task, the following skills can be improved:

- Developing pattern-based programming logic.
- Improving logical thinking and problem-solving skills.
