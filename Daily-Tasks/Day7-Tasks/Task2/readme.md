# Day 7 – Java Daily Tasks

## 📌 Task 2 – Print a Number Pyramid Pattern Using Nested For Loops

### Project Overview

This task focuses on printing a number pyramid pattern using nested `for` loops in Java. It helps understand how multiple loops work together to create structured number patterns.

The program uses an outer loop to control the rows and an inner loop to print the numbers in each row.

### Key Features

- Accepts the required number of rows from the user.
- Uses nested `for` loops to generate the pyramid pattern.
- Prints numbers in a structured pyramid format.
- Controls the number of iterations based on the user's input.
- Displays the final pattern in the console.

### Concepts Practiced

- Java `for` loop
- Nested `for` loops
- Scanner class for user input
- Variables and data types
- Loop initialization and conditions
- Increment operations
- Pattern programming
- Logical thinking

## 🛠️ Technologies Used
