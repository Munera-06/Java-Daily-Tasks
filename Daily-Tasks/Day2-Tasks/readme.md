# Day 2 – Java Daily Tasks

## Project Overview

This folder contains three Java programming tasks completed as part of my daily Java learning practice. The purpose of these tasks is to strengthen my understanding of Java fundamentals, improve logical thinking, and gain practical experience in writing and executing Java programs.

Each task focuses on practising programming concepts through code implementation. These exercises help me become more familiar with Java syntax, program structure, and problem-solving techniques.

- **Programming Language:** Java
- **IDE:** Eclipse IDE
- **Repository Platform:** GitHub
