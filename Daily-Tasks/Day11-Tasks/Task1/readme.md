# Day 11 – Task 1: Count Vowels and Consonants

## Project Overview

The Count Vowels and Consonants program is a Java application that counts the number of vowels and consonants in a given text.

Vowels are the letters **A, E, I, O, U**. The remaining English alphabet letters are called consonants.

**Example:**
- Input: Hello World
- Vowels: 3
- Consonants: 7

- **Programming Language:** Java
- **IDE:** Eclipse

## Program Description

This program accepts a text input from the user and counts the total number of vowels and consonants using a loop and conditional statements.

### How the Program Works

1. Get a text input from the user using the Scanner class.
2. Initialize two variables to store the vowel and consonant counts.
3. Convert each character into lowercase to handle both uppercase and lowercase letters.
4. Use a loop to access each character in the input.
5. Check whether the character is an alphabet letter.
6. If the character is A, E, I, O, or U, increase the vowel count.
7. Otherwise, increase the consonant count.
8. Display the total number of vowels and consonants.
