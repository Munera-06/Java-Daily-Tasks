# Day 11 – Task 4: Addition of Two Matrices

## Project Overview

The Addition of Two Matrices program is a Java application that adds two matrices of the same size and displays the resulting matrix.

Matrix addition is performed by adding the corresponding elements from both matrices.

**Example:**

Matrix A:
```text
1  2
3  4
```

Matrix B:
```text
5  6
7  8
```

Result:
```text
6   8
10  12
```

- **Programming Language:** Java

## Program Description

This program accepts two matrices from the user and performs addition by adding their corresponding elements. The resulting values are stored in a third matrix and displayed as the sum.

### How the Program Works

1. Get the number of rows and columns from the user.
2. Create two matrices and one result matrix with the given dimensions.
3. Get the elements of the first matrix.
4. Get the elements of the second matrix.
5. Use nested loops to access the corresponding elements.
6. Add the elements of both matrices and store the result in the third matrix.
7. Display the resulting matrix.
