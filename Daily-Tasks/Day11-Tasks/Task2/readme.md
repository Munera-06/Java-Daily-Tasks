# Day 11 – Task 2: Count Words in a Sentence

## Project Overview

The Count Words in a Sentence program is a Java application that counts the total number of words in a sentence entered by the user.

A word is generally separated from another word by a space.

**Example:**
- Input: Java is a programming language
- Total Words: 5

## Technology Used

- **Programming Language:** Java
- **IDE:** Eclipse

## Program Description

This program accepts a sentence from the user and calculates the total number of words using Java string handling methods.

### How the Program Works

1. Get a sentence from the user using the Scanner class.
2. Remove unnecessary spaces from the beginning and end of the sentence.
3. Check whether the sentence is empty.
4. Split the sentence into individual words using spaces.
5. Count the number of words.
6. Display the total word count.

## Example Output

```text
Enter a sentence: Java is a programming language

Total number of words: 5
```

## Java Concepts Practiced

- Scanner class for user input
- String handling
- trim() method
- split() method
- String array
- Conditional statements
- Variables and data types

## Learning Outcome

Through this program, I practiced handling strings and counting words in a sentence. I learned how to use Java string methods to process user input and find the total number of words.
