# Day 11 – Task 3: Search an Element in an Array

## Project Overview

The Search an Element in an Array program is a Java application that searches for a specific element in an array entered by the user.

It checks each element in the array and determines whether the given search value is present.

**Example:**
- Array: 10, 20, 30, 40, 50
- Search Element: 30
- Result: Element found at position 3

## Technology Used

- **Programming Language:** Java
- **IDE:** Eclipse

## Program Description

This program accepts array elements and a search value from the user. It uses a loop to check whether the search element exists in the array.

### How the Program Works

1. Get the size of the array from the user.
2. Create an integer array based on the given size.
3. Get the array elements using the Scanner class.
4. Ask the user to enter the element to search.
5. Use a loop to compare the search element with each array element.
6. If a match is found, display the element's position.
7. If no match is found, display that the element is not present in the array.
