## How to Run the Programs

1. Open Eclipse IDE.
2. Open the Java project containing the daily tasks.
3. Navigate to the required task folder.
4. Open the Java source file.
5. Locate the class containing the `main()` method.
6. Right-click the file and select **Run As → Java Application**.
7. View the output in the Eclipse Console.
8. Test with different inputs if the program accepts user input.
