# Day 8 – Java Daily Tasks

## 📌 Task 2 – Print an Inverted Left-Aligned Star Triangle Pattern Using Nested For Loops

### Project Overview

This task focuses on printing an inverted left-aligned star triangle pattern using nested `for` loops in Java. The program uses an outer loop to control the rows and an inner loop to print stars in decreasing order.

It helps improve understanding of nested loops, loop conditions, and pattern-based programming.

### Key Features

- Accepts the required number of rows from the user.
- Uses nested `for` loops to generate the inverted pattern.
- Prints stars in a left-aligned triangle format.
- Decreases the number of stars in each row.
- Displays the generated pattern in the console.

### Concepts Practiced

- Java `for` loop
- Nested `for` loops
- Scanner class for user input
- Variables and data types
- Loop conditions
- Decrement operations
- Star pattern programming
- Logical thinking

## 🛠️ Technologies Used
