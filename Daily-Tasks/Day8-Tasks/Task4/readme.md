# Day 8 – Java Daily Tasks

## Task 4: Increasing Number Triangle Pattern

### Project Overview
This Java program prints an increasing number triangle pattern using nested `for` loops. It displays numbers in a triangular format, with the number of values increasing in each row.

### Task Description
The program accepts the number of rows from the user and prints an increasing number triangle pattern. Nested loops are used to control the rows and the numbers printed in each row.

### Key Features
- Accepts the number of rows from the user.
- Prints an increasing number triangle pattern.
- Uses nested `for` loops to generate the pattern.
- Displays numbers in an organized triangular structure.

### Concepts Practiced
- Java `for` loop
- Nested `for` loops
- Scanner class for user input
- Variables and increment operations
- Number pattern logic
- Basic Java programming

### Technologies Used
