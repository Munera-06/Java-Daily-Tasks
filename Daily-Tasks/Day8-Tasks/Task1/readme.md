# Day 8 – Java Daily Tasks

## 📌 Task 1 – Print an Inverted Right-Aligned Star Triangle Pattern Using Nested For Loops

### Project Overview

This task focuses on printing an inverted right-aligned star triangle pattern using nested `for` loops in Java. The program uses an outer loop to control the rows and inner loops to print spaces and stars in the correct order.

It helps improve understanding of nested loops, pattern formation, and loop execution.

### Key Features

- Accepts the required number of rows from the user.
- Uses nested `for` loops to generate the pattern.
- Prints spaces to align the triangle towards the right.
- Decreases the number of stars in each row.
- Displays the inverted star triangle in the console.

### Concepts Practiced

- Java `for` loop
- Nested `for` loops
- Scanner class for user input
- Variables and data types
- Increment and decrement operations
- Conditional statements
- Pattern programming
- Logical thinking

## 🛠️ Technologies Used
