# Day 8 – Java Daily Tasks

## 📌 Task 3 – Print a Right-Aligned Star Triangle Pattern Using Nested For Loops

### Project Overview

This task focuses on printing a right-aligned star triangle pattern using nested `for` loops in Java. The program uses an outer loop to control the rows, while inner loops print spaces and stars to create the required right-aligned triangle shape.

It helps develop a better understanding of nested loops, spacing, and pattern-based programming.

### Key Features

- Accepts the required number of rows from the user.
- Uses nested `for` loops to generate the star pattern.
- Prints spaces to align the triangle towards the right.
- Increases the number of stars in each row.
- Displays the final pattern in the console.

### Concepts Practiced

- Java `for` loop
- Nested `for` loops
- Scanner class for user input
- Variables and data types
- Loop conditions
- Increment operations
- Space and star pattern formation
- Logical thinking
