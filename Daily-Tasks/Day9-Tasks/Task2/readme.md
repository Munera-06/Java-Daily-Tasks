# Day 9 – Java Daily Tasks

## Task 2: Inverted Pyramid Star Pattern

### Project Overview
This Java program prints an inverted pyramid star pattern using nested `for` loops. It arranges stars and spaces to create an upside-down pyramid shape.

### Task Description
The program accepts the number of rows from the user and prints an inverted pyramid star pattern. Nested loops control the spaces and stars in each row to form the pattern.

### Key Features
- Accepts the number of rows from the user.
- Prints an inverted pyramid-shaped star pattern.
- Uses nested `for` loops to control rows and columns.
- Arranges spaces and stars to create the inverted shape.

### Concepts Practiced
- Java `for` loop
- Nested `for` loops
- Scanner class for user input
- Variables and decrement operations
- Pattern printing logic
- Basic Java programming
