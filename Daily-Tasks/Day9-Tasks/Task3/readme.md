# Day 9 – Java Daily Tasks

## Task 3: Sort Array Elements in Ascending Order

### Project Overview
This Java program sorts the elements of an array in ascending order. It arranges the numbers from the smallest value to the largest value using basic array operations and loops.

### Task Description
The program accepts array elements from the user and sorts them in ascending order. It compares the array elements and swaps their positions whenever necessary to arrange them in the correct order.

### Key Features
- Accepts array elements from the user.
- Sorts numbers in ascending order.
- Compares array elements using nested loops.
- Swaps elements to arrange them correctly.
- Displays the sorted array.

### Concepts Practiced
- Java arrays
- Nested `for` loops
- Scanner class for user input
- Conditional statements (`if`)
- Temporary variables
- Swapping array elements
- Ascending order sorting logic

### Technologies Used
- Java
- Eclipse IDE
- Git and GitHub

### Learning Outcomes

- Practiced comparing and swapping array elements.
- Learned how to arrange numbers in ascending order.
- Improved logical thinking and problem-solving skills.
