# Day 9 – Java Daily Tasks

## Task 1: Pyramid Star Pattern

### Project Overview
This Java program prints a pyramid star pattern using nested `for` loops. It displays stars in a pyramid shape by arranging spaces and stars in each row.

### Task Description
The program accepts the number of rows from the user and prints a pyramid star pattern. Nested loops are used to control the spaces and stars to create the pyramid shape.

### Key Features
- Accepts the number of rows from the user.
- Prints a pyramid-shaped star pattern.
- Uses nested `for` loops to manage rows and columns.
- Arranges spaces and stars to maintain the pyramid structure.

### Concepts Practiced
- Java `for` loop
- Nested `for` loops
- Scanner class for user input
- Variables and increment operations
- Pattern printing logic
- Basic Java programming

### Technologies Used

- Eclipse IDE

### Learning Outcomes
