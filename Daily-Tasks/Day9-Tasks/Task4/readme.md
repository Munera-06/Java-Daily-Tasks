# Day 9 – Java Daily Tasks

## Task 4: Print Non-Repeated Elements in an Array

### Project Overview
This Java program identifies and prints the non-repeated elements in an array. It uses array operations and loops to find the elements that appear only once.

### Task Description
The program accepts array elements from the user and checks how many times each element occurs. It prints only the elements that appear exactly once in the array.

### Key Features
- Accepts array elements from the user.
- Checks the occurrence of each array element.
- Identifies elements that appear only once.
- Prints all non-repeated elements.
- Uses loops and conditional statements to perform the operation.

### Concepts Practiced

- Scanner class for user input
- Conditional statements (`if`)
- Variables and counters
- Element comparison
- Basic array logic
